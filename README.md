As part of the project, a regression model was developed for the Houses dataset, 
where the target variable is median_house_value. Several key steps were taken to 
build the model: 
Week1: data analysis to understand the dataset and correlations.
Week2: preprocessing and normalization of data to prepare features for training. 
Division of data into training and validation sets to evaluate performance.
Week3: building a final model, conducting various experiments to improve it, 
hyperparameter search

Various experiments were conducted and monitored to tune the model and find the best
parameters.An automatic search for the best model parameters was also implemented 
using the keras_tuner library.

Finally, the project included evaluating the results using appropriate regression 
metrics. All stages of the project are described in the Jupyter notebook itself.
